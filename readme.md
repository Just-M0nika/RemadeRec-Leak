# RecRemade Leak

RecRemade is a 2023 server who's source was based off of SSCS which is based off of FemRec.

## Why I did it

To help spread awareness on how insecure these new revivals can be, ESPECIALLY if you're skidding/using another server as base or even reference. 
Vibecoded servers are not safe either, if you are not already experienced in coding or a little bit of cybersecurity you should NOT be making a revival until you are.

Let this be a lesson to anyone thinking of making a revival or already in the process of making a revival. If you do not know what you are doing you are not only risking the data of all of your users but possibly full control over whatever computer your server is running on.

## How I did it

There is a vulnerability allowing full read and write access to anywhere on the filesystem.
This vulnerability is present in EVERY SINGLE revival that is based off of (or is just directly using) FemRec or SSCS.
Through this exploit I was able to pull every file (including their databases), and even upload my own files.
